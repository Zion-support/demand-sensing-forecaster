# Demand Sensing Forecaster

**Zion Demand Sensing Forecaster** — short-horizon demand sensing that blends POS, weather, local events and promo signals.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/demand-sensing-forecaster/

## ✨ Features
- **Short-horizon sensing** — daily/weekly forecasts that react to fresh POS signals.
- **External signals** — weather, holidays, local events and promo calendars built in.
- **SKU-location granularity** — forecasts at the level replenishment actually needs.
- **Forecast-value-add tracking** — proves lift vs. naive baseline per planner.
- **One-click push** — feeds forecasts to planning/ERP via API or CSV.
